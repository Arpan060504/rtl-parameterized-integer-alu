# Integer ALU (Version 1) - Verilog RTL

A parameterized **Integer Arithmetic Logic Unit (ALU)** written in Verilog HDL with a self-checking testbench.

This project implements the fundamental execution unit found inside almost every processor. It performs basic arithmetic and logical operations while generating commonly used processor status flags.

---

# Project Objective

The goal of Version 1 was to design a clean, synthesizable RTL implementation of a basic integer ALU while strengthening:

- RTL coding style
- Combinational logic design
- Parameterized Verilog
- Status flag generation
- Self-checking verification
- Corner case testing

This project serves as the first building block toward designing a complete processor execution unit.

---

# Features

Implemented operations:

| Opcode | Operation |
|---------|-----------|
|000|Addition|
|001|Subtraction|
|010|Bitwise AND|
|011|Bitwise OR|
|100|Bitwise XOR|
|101|Set Less Than (SLT)|

Generated processor flags:

- Zero
- Carry
- Overflow
- Negative

Parameterized data width (default = 8 bits).

# ALU Architecture

```text
                 +--------------------------------+
                 |          Integer ALU           |
                 |                                |
      A -------->|                                |
                 |                                |------> Result
      B -------->|                                |
                 |                                |
 ALU Opcode ---->|                                |
                 |                                |
                 +--------------------------------+
                     |      |      |      |
                     |      |      |      |
                     V      V      V      V

                   Zero  Carry Overflow Negative
```

# Module Interface

## Inputs

| Signal | Width | Description |
|---------|------|-------------|
|a|DATA_WIDTH|Operand A|
|b|DATA_WIDTH|Operand B|
|alu_op|3|Selects ALU operation|

---

## Outputs

| Signal | Description |
|---------|-------------|
|result|Arithmetic/Logical result|
|zero|Result equals zero|
|carry|Unsigned carry generated during addition|
|overflow|Signed arithmetic overflow|
|negative|MSB of result|

# Supported Operations

## Addition

```
Result = A + B
```

Generates

- Carry Flag
- Overflow Flag

---

## Subtraction

```
Result = A - B
```

Generates

- Negative Flag
- Zero Flag

(Current version does not yet implement signed overflow detection.)

---

## Logical Operations

- AND
- OR
- XOR

These operations only modify the result and Zero/Negative flags.

---

## Set Less Than (SLT)

Outputs

```
1  if A < B

0  otherwise
```

---

# Status Flags

## Zero Flag

```
Zero = (Result == 0)
```

Indicates the output equals zero.

---

## Carry Flag

Generated only during addition.

```
Carry = Internal_Result[DATA_WIDTH]
```

Used for unsigned arithmetic.

---

## Overflow Flag

Detects signed overflow during addition.

Overflow occurs when

Positive + Positive = Negative

or

Negative + Negative = Positive

---

## Negative Flag

```
Negative = Result[MSB]
```

Indicates the result is negative in two's complement representation.

---

# RTL Design Flow

1. Decode ALU opcode
2. Execute selected operation
3. Generate Result
4. Generate Status Flags
5. Drive Outputs

---

# Verification Strategy

A self-checking Verilog testbench was developed.

Each test automatically compares

- Result
- Zero Flag
- Carry Flag
- Overflow Flag
- Negative Flag

against expected outputs.

Any mismatch increments an error counter.
